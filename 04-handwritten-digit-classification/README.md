## Project Summary

The goal of this project was to build a neural network for handwritten digit classification using PyTorch and the MNIST dataset. The model achieved **91.55% accuracy** on the test dataset. 

The confusion matrix showed that digit **1** was classified the best, with **1,108 correct predictions**, while digit **5** was the most difficult, with **762 correct predictions**. This project provided a practical introduction to PyTorch, neural network training, GPU acceleration with CUDA, and model evaluation.
