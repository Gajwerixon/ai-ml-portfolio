A collection of practical Artificial Intelligence and Machine Learning projects, covering classical machine learning, deep learning, computer vision, natural language processing, audio and video processing, generative AI, and recommendation systems.

The projects are organized progressively, starting with fundamental machine learning concepts and gradually moving toward more advanced AI applications.
